2  Composing maps

Communication of geographical data and concepts through maps is a fundamental skill for spatial scientists. Creating maps requires both the ability to make them complete, correct and functional, and the flair to make them interesting and attractive. This exercise introduces the QGIS Print Layout window, and is how you generate the maps for your wind farm project.

NoteLearning aims

To create functionally complete maps in QGIS for print or digital output. You will learn how to create a 1:1,000,000 scale map of Wales illustrating mean wind speed and county boundaries necessary for making Map 1.

2.1 Creating a print layout

  1. Launch QGIS and create a new project

  2. Add the British_Isles_land_polygons.gpkg, Wales_border.gpkg, and Wales_Principal_Areas.gpkg layers to your project (the latter two are in the UK_Boundaries folder)

  3. Label the Principal Areas of Wales in Welsh or English

  4. To create a Print Layout:

    1. Click Project → New Print Layout... (and find the shortcuts to this window)
    2. Give the print layout an appropriate title
    3. Click Project → Layout Manager.... You can see here the Print Layout now saved within your project. You can create more than one print layout per project. Use this panel to access and organise layouts
    4. Click Close

  5. Change the page orientation and size, so it fits onto an A4 portrait document with space beneath to accommodate a caption (see ?sec-WP):

    1. Right‑click on the blank print layout
    2. Click Page Properties...
    3. Change Size to Custom
    4. Reduce the map Height (e.g. to 270)
    5. Change Orientation to Portrait

2.2 Adding and adjusting a map item

  1. Click Add Item → Add Map (look for the shortcut)

  2. Draw a map onto the print layout. Map 1 should now appear under the Items tab

  1. If necessary, adjust the map using the squares on the map boundaries so it fits more comfortably on the page

  2. Select Map 1 from the Items panel

  3. Set Scale to 1000000 (i.e. 1:1,000,000)

  4. Use the Move item content () and Select/Move item () tools, and adjust the Scale value, to compose the map so that all of Wales is visible

  5. Experiment with making fine adjustments to the scale by holding down the Ctrl key (windows) or Command key (mac) and scrolling the mouse wheel

  6. Once you’re satisfied with the scaling, framing, and position, freeze the view in place by checking the box under the lock icon () for Map 1 in the Items panel

  7. From the Map Canvas window, adjust layer styles:

    1. Choose colours, border widths, and fonts that emphasise Wales and the difference between the outline of Wales (physical coast) and Principal Areas boundaries (non‑physical political construct)

  8. Update the Print Layout to reflect your changes using one of these two options:

    1. Click the Refresh icon () in the Print Layout window
    2. Click the Update Map Preview icon () under Item Properties in the Map Canvas window

  9. Click on the Item Properties tab and check Frame

  10. Modify the frame’s Background colour appropriate for representing the ocean

  11. You can modify the Layout and Item Properties of any item selected in the Item window. Note how the options under Layout and Item Properties tab update depending on what item you’ve selected. Remember that:

    1. The order in which map items are listed is how they are also stacked on top of one another in the print layout
    2. Some layer properties (e.g. layer order, style, labeling) are controlled in the Map Canvas

2.3 Adding a scale bar, north arrow, and grid

  1. From the Print Layout window, add a scale bar:

    1. Click Add Item → Add Scale Bar
    2. Drag and drop on the map to place it (you can move it later)
    3. Select the scale bar from the Items panel
    4. Click the Item Properties tab
    5. Adjust the scale bar’s properties, notably Style, Scalebar units, Segments, Frame, and Background

  2. Add a north arrow:

    1. Click Add Item → Add North Arrow
    2. Drag and drop on the map to place it (you can move it later)
    3. Select the north arrow from the Items panel
    4. Click the Item Properties tab
    5. Under SVG Images, search arrow and choose a suitable north arrow
    6. Adjust the north arrow’s properties, notably Fill color and Stroke color

  3. Add a grid (aka graticule):

    1. Select Map 1 from the Items panel
    2. Click the Item Properties tab
    3. Expand Grids
    4. Click Add a new grid ()
    5. Click Grid 1 → Modify Grid...
    6. Set CRS to EPSG:4326 - WGS 84
    7. Set X and Y intervals to 1 degrees
    8. Check Draw Coordinates
    9. Adjust the grid’s properties, notably Grid type, Frame, and Draw Coordinates. Can you adjust the labels for readability, soften the gridlines, and reduce unnecessary trailing zeros?

  4. You may find that some of the map items, notably the coordinates, are now beyond the edge of the page. These will be lost when the map is exported! In these cases, you will need to adjust the map size periodically as you experiment with how to best arrange map items and the caption (see Section 2.2). Check how using Guides can aid you in aligning map items perfectly on the page

2.4 Adding labels and a legend

  1. Add a map title label:

    1. Click Add Item → Add Label
    2. Drag and drop on the map to place it (you can move it later)
    3. Select the label from the Items panel
    4. Click the Item Properties tab
    5. Adjust the label’s properties, notably Main Properties, Font, Rotation, Frame, and Background

  2. Add a legend:

    1. Click Add Item → Add Legend
    2. Drag and drop on the map to place it (you can move it later)
    3. Select the legend from the Items panel
    4. Click the Item Properties tab
    5. Uncheck Auto update to enable modifications to the legend
    6. Experiment with the legend toolbar icons () to improve the legend
    7. Adjust the legend’s properties, notably Arrangement, Fonts and Text Formatting, Columns, Symbol, Spacing, Frame, and Background

2.5 Adding raster data

  1. Add your first raster layer in QGIS:

    1. From the menu bar in the Map Canvas, click Layer → Add Layer → Add Raster Layer...
    2. Click the Browse icon () and navigate to the folder where the data is stored, i.e. GEG276
    3. Open the Wales_mean_windspeed folder and click on any of the .tif raster layers
    4. Click Open → Add → Close

  2. Change the raster layer’s colour ramp:

    1. Open the layer’s Properties... → Symbology
    2. Use the Render type drop-down menu to select Singleband pseudocolor
    3. Under Color ramp, select an appropriate colour ramp for the data (or pick one you just really like!)
    4. Click OK

  3. Adjust the order and modify the properties of the Wales Principal Areas and windspeed layers so both are visible at the same time. Hint: modifying Fill or Transparency properties may do nicely, but be careful to not break the link between the map and legend colours

  4. In the Print Layout window, select Map 1 and click Update Map Preview under the Item Properties tab

  5. If the colour scale for the raster layer does not appear in the legend, add it

  6. Experiment with improving the aesthetics of the updated legend

  7. Select Map 1 from the Items panel

  8. Under Item Properties, check the Lock layers and Lock styles for layers to prevent further changes to the map. Uncheck if you need to make edits

2.6 Adding an inset map

  1. Add a second map to provide an inset showing the British Isles (see Section 2.2)

  2. Modify this second map to create an effective inset map that provides geographic context for the main map:

    1. Adjust the inset map so the whole of the British Isles are visible
    2. Modify which layers should be displayed by turning layer visibility on and off or changing the layer order
    3. Modify the layers’ symbology
TipScale matters

Place emphasis on only a few, simply presented layers that are useful at this scale. Aim to be minimalist to avoid cluttering the map. Note: because your map of Wales (Map 1) is locked, it’s not affected by changes in layer visibility or symbology being made for the inset. Herein lies the power of locking layers.

  1. Add an extent indicator on your main map to connect it to the inset map:

    1. Select your inset map (Map 2) from the Items panel
    2. Under Item Properties, expand the Overviews tab
    3. Click Add a new overview ()
    4. Click Overview 1
    5. Set the Map frame to your main map (Map 1)
    6. Adjust the Frame style to draw a hollow rectangle with a thick line, to easily show the main map’s extent
    7. Experiment further, especially with Fill color, Stroke color, and Join style

  2. Projects can get rapidly out of control when multiple layers are used to build a map. It’s important to remove redundant layers and label items appropriately. E.g. try renaming Map 1 to Main, and Map 2 to Inset. This will help when you need to revisit and adjust your maps

2.7 Exporting your map

  1. Ensure both maps have Lock layers checked so that your formatting is captured in the exported maps

  2. To export your map as an image:

    1. Click Layout → Export as Image...
    2. Select a suitable location to save the map
    3. Set the image format to PNG (.png)
    4. Click Save
    5. Set Export resolution to 300 dpi (300 dpi is suitable for viewing on a screen, 600 dpi is better for printing)
    6. Click Save

  3. Congratulations - you’ve created your first QGIS map assignment. Now make any revisions (including the map height) to be able to submit the best Map 1 that you can!

NoteLearning outcomes

By the end of this exercise you should be able to:

  1. Create a scaled print layout in QGIS, setting page size and orientation and framing a map item at a fixed scale
  2. Add the essential furniture of a complete map — scale bar, north arrow, graticule, title, caption, and legend — and adjust their properties for clarity
  3. Integrate raster and vector data in a single layout, applying pseudocolour rendering and managing layer order and transparency so both remain legible
  4. Construct an inset map using locked layers and an overview frame to place the main map in its wider geographic context
  5. Export a print-ready map to PDF with appropriate vector, text, and compression settings, and appreciate how locking layers preserves scale integrity
