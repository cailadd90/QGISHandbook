3  Geocoding and population

Date of practical: 16th October 2025

The location and density of the human population underpin how society is organised. GIS helps one understand human systems, by calculating things like population density, proximity to features, and assigning data to addresses. In the UK, postcodes have been developed as a means to link human activity to physical locations for aiding governance. This exercise explores how postcodes can be used to gather useful population-level information.

NoteLearning aims

To examine the distribution of postcode reference points within Wales, visualise population density, geocode new features onto a map, and count populations within simple catchments.

3.1 Exploring postcode locations

  1. Launch QGIS and create a new project

  2. Import the Wales_Principal_Areas.gpkg layer

  3. Import the Wales_headcounts_at_postcodes_2021.gpkg layer. This dataset contains the number of households and people registered at each postcode (taken from the 2021 Census), combined with coordinates from OS OpenData

  4. Investigate the attribute table and explore how these points are distributed

  5. Using the attribute table, examine areas of very high and very low density and discuss with your neighbour why these spatial patterns may exist

  6. Using attribute table selection and skills from Chapter 1 (Section 1.5), find postcodes with the greatest number of people in the Cardiff (CF), Swansea (SA) and Aberystwyth (SY) areas

  7. Use Google Maps to search for these postcodes, and discuss with your neighbour why these locations have such high population counts

  8. Save your project!

  9. Open the headcounts layer’s Symbology window

  10. Use the drop-down menu to change the symbology source from Single Symbol to Graduated

  11. Set Value to Total (i.e. the UK population in 2021)

  12. Set Method to Size

  13. Click Classify → OK. Point sizes should now reflect population per postcode

3.2 Finding headcount statistics

  1. Click Vector → Analysis Tools → Basic Statistics For Fields...

  2. Set Input layer to the Wales_headcounts_at_postcodes_2021.gpkg layer

  3. Set Field to calcualate statics on to Total

  4. Click Run. Results are presented under the Log tab, and can be viewed in the Results Viewer. Double-clicking Statiscs will open the results in a web browser

  5. Consider what each value means, then discuss with your neighbour what the registered population of Wales in 2021 was (a sense check on google may help!)

  6. Click Close

  7. Calculate the percentage population change in Wales between 2011 and 2021. Show off by being first to tell your neighbour the result

  8. Right-click on the 2011 census headcount layer and click Remove Layer...

TipKeeping things tidy

It’s good practice to remove layers once you’re done with them, to avoid your project becoming too cluttered and confusing.

3.3 Select by location

  1. Calculate basic statistics on a subset of data in a particular location:

    1. Select the Swansea county polygon from Wales_Principal_Areas (forgotten how to do this? Check Section 1.5)
    2. Click Vector → Research Tools → Select By Location...
    3. Set Select features from as Wales_headcounts_at_postcodes_2021
    4. Check are within
    5. Set By comparing to the features from to Wales_Principal_Areas
    6. Check Selected features only. This ensures only postcodes in Swansea are selected
    7. Click Run
    8. If done correctly, you’ll see all postcode centroids in Swansea county have been selected (highlighted yellow)

  2. Use the Basic Statistics For Fields... tool to find the 2021 Total population of Swansea. Make sure Selected features only is checked this time

  3. Calculate the 2021 population of Cardiff county, and calculate the percentage population change in Swansea county between 2011 and 2021. Show off again by beating your neighbour in finding the results

3.4 Creating a heatmap

  1. Click Processing → Toolbox or find the the shortcut ()

  2. Click the drop-down arrow next to Interpolation

  3. Double-click Heatmap (Kernel Density Estimation)

  4. Generate a raster heatmap of population density across Wales:

    1. Set Point layer to Wales_headcounts_at_postcodes_2021
    2. Set Radius to 500 metres
    3. Set Pixel size X and Pixel size Y to 100
    4. Set Weight from field to Total

  5. Experiment with the raster layer’s symbology (see Section 2.5). It may help to hide the 2021 point layer and clear any selections from the principal areas polygons whilst you do this

  6. Experiment with changing the Radius to see how the heatmap changes

  7. Saved your project recently?

3.5 Geocoding new addresses

TipWhat’s geocoding?

Geocoding is the process of converting a human-readable address or place name into geographic coordinates, such as latitude and longitude. It allows a GIS to plot locations on a map. Let’s do some geocoding by plotting where your local Tesco stores are located!

  1. Navigate to the Tesco store locator

  2. Search for stores in the Swansea area

  3. Open Excel

  4. Populate a spreadsheet with the Store name and Postcode of the first seven stores from the website

  1. Save the spreadsheet in a .csv format (UTF-8)

  2. In QGIS, select Plugins → Manage and Install Plugins...

TipThe power of plugins

Plugins are written by QGIS developers and other independent developers who want to extend the core functionality of the software. It is this community-led innovating that makes QGIS such a powerful tool.

  1. Search for mmqgis

  2. Click Install Plugin

  1. Use the MMQGIS tool to attach coordinates to postcode data:

    1. Click MMQGIS → Geocode → Geocode CSV with Web Service
    2. Set Input CSV File as your .csv file
    3. Set Address as your postcode column
    4. Set Web Service as OpenStreetMap / Nominatim
    5. Set Output File Name to your Downloads folder
    6. Set Not Found Output List to your Downloads folder
    7. Click Apply
    8. Wait until Geocoded 7 of 7 appears beneath the tool and check the postcodes appear in the correct places
    9. Click Close
ImportantTemporary output

It’s common in QGIS to create temporary layers, check they’re displaying as intended, then save the output to somewhere more sensible. This is especially true if several steps are needed to create the intended output. Saving these temporary layers to your Downloads folder is a good idea, as you can eventually empty this folder without glogging up valuable space on your OneDrive account with junk data.

3.6 Exporting vector layers

Modify the temporary vector layer and save in a sensible location:

i. From the `Layers` panel, right-click on `temp1` and click `Export` → `Save Features As...`
ii. Set `Format` to `GeoPackage`
iii. Select a suitable location to save the geopackage 
iv. Set 'Layer name' as something sensible, e.g. the same as the file name
v. Set `CRS` to `EPSG:27700`
vi. Under `Select fields to export and their export options`, you can decide what information should appear in the attribute table. Keep things tidy by only including the store name and postcode
vii. Click `OK`

  1. The layer should appear in the Layers panel. Open its attribute table. Does what you’ve just done make conceptual sense? If not - ask!

  2. Remove the temp1 layer from your project

3.7 Using buffers as simple catchments

  1. Create buffers around each postcode point to approximate walking distance from the Tescos store:

    1. Click Vector → Geoprocessing Tools → Buffer...
    2. Set Input layer as your Tesco stores layer (which should now have [EPSG:27700] after the layer name)
    3. Set Distance to 500 metres
    4. Check Dissolve result
    5. Click Run → Close

  1. Using Select by Location (see Section 3.3) and Basic Statistics (see Section 3.2), find the total number of people registered to postcodes within 500 m of Tesco stores

  2. For the final challenge - find the total number of people registered in 2021 within 2 km of Swansea University Singleton Campus (SA2 8PQ) and Bay Campus (SA1 8QE).

The skills you’ve learned here are vital for the wind farm project.

NoteLearning outcomes

By the end of this exercise you should be able to:

  1. Explore postcode-linked census data through the attribute table, examining and explaining spatial patterns of high and low population density
  2. Visualise population density using graduated symbology and kernel density (heatmap) estimation
  3. Geocode addresses from postcodes using a plugin and web service, and export the result as a properly projected vector layer
  4. Calculate population statistics for defined areas and catchments — combining Select by Location, Buffer, and Basic Statistics for Fields tools
  5. Appreciate how postcodes link human activity to physical location, and the value of tidy, well-projected data and temporary layers in a GIS workflow
