4  Combining vector layers

Dates of practical: 23rd and 30th October 2025

Creating spatial and thematic subsets of vector layers is essential GIS practice and a key step in preparing for the wind farm Project. Before you begin, familiarise yourself with the wind farm Project instructions.

You will find data for this exercise on the L: drive under College of Science/Geography/GEG276. Read alongside GIS_guide_to_practical_exercises.

NoteLearning aims

Clip small subsets from large vector datasets, create dissolved buffers around line and polygon layers, select subsets by attribute, and combine layers.

4.1 Investigating your map tile

  1. Launch QGIS, create a new project, and open layer Wales_border from UK_Boundaries.

  2. From Wales_map_tiles, open the layer corresponding to your assigned OS map tile to see where your wind farm project will focus.

  3. Calculate the area of your 20 × 20 km map tile (square metres) and its perimeter (metres).

  4. Open the attribute table for your map tile. This layer has one polygon. Open the Field Calculator and explore $area and $perimeter. Values differ slightly from expectations due to Earth curvature and projection distortion.

  5. Using prior methods, calculate the number of people living within your polygon at the 2021 Census. Compute population density for your tile.

4.2 Clipping polygon and point layers

  1. Open layers in Wales_protected_areas. Investigate what “protected area” means and explore attribute tables. Save your project regularly.

  2. Clip these layers to your map tile using Vector → Geoprocessing Tools → Clip. Input: the dataset to clip; Overlay: your map tile polygon. Choose Save to File, GeoPackage format, sensible names, and folder structure. Examine the new clipped layer.

  3. Clip each protected area dataset relevant to your tile. Save clipped layers with appropriate filenames.

  4. Merge protected area layers with Vector → Data Management Tools → Merge Vector Layers to create a single protected‑areas layer. Alternatives include Union or MMQGIS → Merge.

  5. Dissolve internal boundaries with Vector → Geoprocessing Tools → Dissolve. Save to disk. Use the field calculator to find total protected area and percentage of your tile.

  6. Using prior data, clip existing or planned wind farms to your map tile. Save your work.

4.3 Clipping line layers and adding buffers

  1. From British_Isles_geofabrik/wales, open waterways, water, railways, and roads. Explore attributes.

  2. Clip each of these layers to your tile. Name outputs sensibly.

  3. Review wind farm Project constraints (e.g., distances from transport links and water bodies).

  4. Create buffers with Vector → Geoprocessing Tools → Buffer for each transport and water layer. Dissolve boundaries (during or after) and optionally clip buffers to the tile polygon.

  5. Create buffers for existing/planned wind farms if appropriate. Name layers carefully and organise files.

  6. Merge buffered layers if helpful.

  7. Consider merging clipped layers before buffering as an alternative workflow.

4.4 Selecting elements by attribute

  1. Open gis_osm_landuse_a_free_1 (landuse) and clip to your map tile.

  2. Examine the attribute table. Open Select by expression, expand Fields and Values, choose fclass, and list unique values. Decide which classes are relevant (e.g., residential, forest).

  3. Use Select by expression to select features, e.g. "fclass" = 'residential'.

  4. Save selected features to a new layer (Layer → Save As or Export → Save Selected Features As). Name and store methodically.

  5. Repeat for other relevant landuse classes.

4.5 Taking stock of planning constraints

  1. Review the layers that represent areas unsuitable for wind farm development because of their position within, or proximity to, man‑made or natural features.

  2. Explore unconstrained areas large enough for a wind farm. Use subsequent exercises to evaluate the best site.

TipLearning outcomes

By the end of this exercise you should:

  1. Calculate area and perimeter of a polygon using the Field Calculator.
  2. Clip point, line, and polygon vector layers.
  3. Create and dissolve buffers around point, line, and polygon layers.
  4. Select and save subsets from a vector layer by attribute.
  5. Build layers that represent your tile’s wind farm planning constraints.
