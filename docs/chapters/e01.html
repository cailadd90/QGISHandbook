1  Getting started

To master QGIS, one must start with the basics. This exercise introduces the foundational skills that will underpin the development of your wind farm project and beyond - including your dissertation. Take your time, ask questions, and make sure you are confident with each step before moving on.

NoteLearning aims

To become familiar with the Quantum GIS (QGIS) environment for visualising and processing geospatial data. You will learn how to open various types of data layer, adjust the way they look, explore their attributes, and select features for further analysis.

1.1 Starting up

  1. Follow the steps here to access all the datasets you need for the practicals and the final project

  2. Launch QGIS. This could be on a University computer, via a remote desktop, or on your own computer

  3. From the menu bar, click Project → New. Find the shortcut icon to create a new project

  4. Add your first vector layer in QGIS:

    1. From the menu bar, click Layer → Add Layer → Add Vector Layer...
    2. Click the Browse icon ()
    3. Navigate to the folder where the data is stored, i.e. GEG276
    4. Open the British_Isles_land_polygons folder and click on the corresponding .gpkg vector layer
    5. Click Open → Add → Close. This dataset from the OpenStreetMap project consists of polygons representing the many islands making up the British Isles. Note the layer is now listed under the Layers panel. You can also drag-and-drop datasets from the browser straight into the Map Canvas

1.2 Navigation

  1. Use the Map Navigation Toolbar to explore this dataset by panning and zooming

  1. Try using the mouse scroll wheel as a shortcut

  2. Make yourself familiar with navigating around the Map Canvas by losing yourself! Pan and zoom until you can’t see the British Isles layer anymore. Once lost, right-click on the layer in the Layers panel and click Zoom to Layer(s) to easily return to view that layer

1.3 Adjusting style properties

  1. To adjust a layer’s symbology:

    1. From the Layers panel, right-click on British_Isles_land_polygons and click Properties... → Symbology. A useful shortcut to Properties is to double-click the layer
    2. Click Simple Fill and experiment with changing the layer symbology’s colours, styles, and widths. You have complete control over how vector layers appear. When designing a map, consider carefully how to choose an appropriate style for each layer
    3. Click Apply → OK when you’ve finished editing the layer’s symbology

  2. From the menu bar, click Project → Save and save your project to a suitable location. Find the shortcut. Remember to save regularly from now on!

1.4 Measuring geospatial objects

  1. Click the drop-down arrow next to the Measure icon to select the appropriate tool for measuring:

    1. The distance between the extreme cardinal points of Great Britain (in miles)
    2. The approximate area of the Isle of Man (in square kilometres)
  1. Use left-click to add points, and right-click to stop taking the length / area measurements

1.5 Exploring the Attribute Table

  1. From the Layers panel, right-click on British_Isles_land_polygons and click Open Attribute Table. An attribute table is a fundamental part of all GIS datasets. Each row of the table corresponds to a single feature (e.g. a polygon) of the vector layer, and each column, or attribute (of which there can be as many as is needed), records a property of the feature (e.g. name, area, circumference). This particular data layer has two attributes: fid (field identifier) and Area

  2. Click the Dock Attribute Table icon () so that you can see both the Map Canvas and Attribute Table on screen at once

  3. To understand how the attribute table corresponds with the vector layer:

    1. Sort the attribute table according to each polygon’s area by clicking the Area column title. Repeated clicks will sort by ascending or descending the values
    2. Click a row number to select the polygon to which it corresponds. The selected polygon in the Map Canvas has now been highlighted yellow
    3. Click the Zoom map to the selected rows icon in the top-right corner () to zoom to the selected polygon in the Map Canvas
  1. Repeat the step above to explore the ten largest islands of the British Isles

Can you name the seventh-largest island of the British Isles?

The seventh-largest island of the British Isles is Ynys Môn / Anglesey.

  1. You can also select features in the Map Canvas to identify their corresponding attributes in the attributes table:

    1. Click the Select Features icon ()
    2. Select (highlight in yellow) the Isle of Wight
    3. In the attribute table, click the Move selection to top icon () to move the selected line of the table to the top
    4. Read the area of the feature - which is in square metres - and convert it to square km (i.e. divide by 1,000,000)

What is the precise area of the Isle of Wight (in square kilometres)?

The precise area of the Isle of Wight was 382 square kilometres.

  1. Click the Deselect features icon () to deselect the current selection. These functions will be very useful later on

1.6 Arranging layers

  1. Add the Wales_Principal_Areas.gpkg layer in the UK_Boundaries folder to your project. This dataset consists of polygons representing the Principal Areas (otherwise known as counties) of Wales. Note this layer will also appear in the Layers panel

  2. Adjust the style of this layer and explore its attribute table

  3. Experiment with switching layer visibility on or off using the tick boxes in the Layers panel (). This becomes essential when managing multiple layers in a project

  4. Change the order of the layers by dragging each upwards or downwards in the layer panel

  5. Move Wales_Principle_Areas to the top of the Layers panel. Notice how the seaward political (Principal Area) boundary of Wales goes beyond the coastline (Land Polygons). This is because the physical land boundary is generally classified according to the mean high water mark, while administrative boundaries are normally classified according to the mean low water mark. That’s Geography!

  6. To categorise the layer’s symbology:

    1. Open the layer’s Symbology window
    2. Use the drop-down menu to change the symbology source from Single Symbol to Categorized
    3. Use the Value drop-down menu to select the attribute name
    4. Click Classify → OK. How colourful!

1.7 Labelling layers

  1. To label layers:

    1. Select Wales_Principal_Areas layer in the Layers panel
    2. From the menu bar, click Layer → Labeling. Find the shortcut to this window (hint - check out Properties...)
    3. Use the drop-down menu to change the labelling source from No Labels to Single Labels
    4. Change the Value drop-down menu to label the Wales Principle Area polygons according to their English or Welsh names

  2. Experiment with modifying the labels by:

    1. Changing the text style () e.g. style and size
    2. Changing the label format () e.g. wrapping and orientation
    3. Adding a text buffer ()
    4. Changing the label placement ()
    5. Playing around with other options. You are in complete control!
    6. Have you saved your project recently?

  3. Now that the Principal Areas have been labelled, zoom out. Notice how QGIS chooses to place and resize the labels so that they remain visible, but switches some of them off to avoid overlapping text. This is a fundamental part of map design and QGIS tries to optimize readability. You can control this behavior through the Labeling window and you are encouraged to experiment.

1.8 Adding and filtering data

  1. Add the vector layer Wales_operational_windfarms.gpkg to your project. These data are from the UK Renewable Energy Planning Database and represent the location of operational wind farms across Wales

  2. Examine the attribute table

  3. Adjust the layer’s style, noting that point data is represented in a different way to polygon data

  4. Label the wind farms by their name or by their generation capacity

  5. Add the vector layer gis_osm_roads_free_1.gpkg, which is in the folder British_Isles_geofabrik → wales, to your project. These data form part of the OpenStreetMap project and represent all roads in Wales. This is a large dataset and may take time to load and display

  6. Once again, for this layer:

    1. Examine the attribute table
    2. Experiment with different styles for line data

  7. There is a lot of data here! So let’s subset it. There are many ways to make subsets of data layers to select only the data you need or that you want to display. To filter the data universally:

    1. Right-click on the roads layer and click Filter...
    2. This tool allows you to easily see all the unique values contained in each field (or column) of the attribute table. Click fclass → All. You can now see all the unique classes of road in the vector layer
    3. Under Provider Specific Filter Expression, type "fclass" IN ('primary', 'trunk', 'motorway'). Make sure of precise punctuation and spacing
    4. Click OK. Your map should now only display roads classed as primary and secondary. A funnel icon () has also appeared next to the layer in name in the `Layers’ panel, to remind you a filter has been applied

  8. Label the roads with the attribute ref (i.e. the road number). See how these labels are displayed as you zoom in and out of the map

  9. To remove the filter:

    1. Click the funnel icon () next to the roads layer
    2. CLick Clear → OK

  10. To filter the data by defining what is presented in the map:

    1. Open the layer’s Symbology window
    2. Use the Categorized option to categorise the road symbology according to the fclass attribute
    3. Delete all the road classes except primary, trunk, and motorway using the Delete icon (). See if you can make this task easier for yourself by using the Shift and Ctrl keys…
    4. Double-click the line symbol per category to choose a suitable symbology for these remaining roads (e.g. thick red for primary, very thick light blue for motorway)

  11. Add the gis_osm_waterways_free_1.gpkg vector layer in the British_Isles_geofabrik → wales folders. What colour would be best for this layer?

1.9 Adding external data

  1. Navigate to datamap.gov.wales

  2. Search for “Wales Coast Path” and click on the link

  3. Under Select spatial data format, choose OGC Geopackage and click Download

  4. Move the downloaded file to your OneDrive

  5. Add the layer to your project and explore it

  6. Try searching for and downloading other GIS data files from datamap.gov.wales, geofabrik.de, or any another source. Searching for geospatial datasets should show you how easy it can be to find and download data from the internet. This will also provide inspiration for dissertation ideas, which is now on your horizon

1.10 Have you finished?

  1. Congratulations! You’ve learned the basics of QGIS. Make sure that you’ve understood all the steps above. Repeat if necessary, and ask for help or advice from the demonstrators. You will need this knowledge in future exercises and for the assessments.
NoteLearning outcomes

By the end of this exercise you should be able to:

  1. Create and manage a QGIS project by adding vector layers from various sources and using the navigation tools to pan, zoom, and return to a layer’s extent
  2. Adjust the appearance of spatial data through symbology, layer ordering, and labelling to build a clear, readable map
  3. Explore the attribute table to understand how features relate to their attributes, sorting records and selecting features reciprocally between table and map canvas
  4. Measure and filter geographic data by obtaining lengths and areas, converting between units, and subsetting layers using filter expressions and categorised symbology
  5. Appreciate how cartographic and administrative conventions shape spatial representation, from automated label placement to the way boundaries are drawn
