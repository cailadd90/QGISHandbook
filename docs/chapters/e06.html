6  Wind farm area polygon, viewshed, and impact

Dates of practical: 20th and 27th November and 11th December 2025

This exercise is all about applying the skills you’ve gained over the past five exercises, to cement your GIS skills and successfully complete the wind farm project. You will also create a new polygon to represent your wind farm location, and create viewsheds to identify who may be impacted by the wind farm development.

This exercise will guide you through the requirements for making Map 4

NoteLearning aims

Create and edit a polygon to represent a wind farm, calculate its area, create a viewshed, and count the population living within view of the proposed wind farm.

6.1 Starting point

  1. Launch QGIS and create a new project

  2. Add the various constraint vector and wind speed raster layers within your map tile (created from previous chapters) to the project

6.2 Wind farm polygon creation

6.2.0.1 Create new vector layer

  1. Create a new GeoPackage vector layer representing your optimal wind farm location:

    1. Click Layer → Create Layer → New GeoPackage Layer...
    2. Click the Browse icon () next to Dataset to save the wind farm location vector somewhere sensible
    3. Set Geometry type as Polygon
    4. Set the CRS as EPSG:27700
    5. Click OK
    6. From the Layers panel, right‑click on the new layer and click Toggle Editing or find the shortcut ()

    You can tell when a layer’s in edit mode, as a pencil icon appears over the layer’s symbol. Edits are temporary until you save them. This allows you to undo any mistakes you may have made. But beware - once saved, mistakes can’t be undone!

    1. From the Digitizing Toolbar, click Add Polygon Feature
    1. Left‑click on the Map Canvas to draw vertices (points), outlining your optimum wind farm location
    2. Once your polygon is complete, right‑click to finish
    3. click OK
    4. If necessary, adjust the polygon by:
      1. Clicking the Vertex Tool ()
      2. Selecting a polygon vertex
      3. Moving the cursor to the desired location and pressing left-click
    5. Click the Toggle Editing icon () once more to turn off editing
    6. Click Save

6.3 Enable snapping

Are you a perfectionist, but you can’t get the edge of your optimum wind farm area to abut a constraint layer? Well the snapping tool is for you! This will pull the cursor up against the edge of a vector layer to aid in the perfect placement of vertices. Try it out by clicking View → Toolbars → Snapping Toolbar, then clicking the Enable Snapping icon ().

6.4 How big is your wind farm?

  1. Calculate the area of the polygon (see Section 4.2.0.1)

A 50 m turbine generates about 750kWh . How many turbines will your windfarm support? Note that as long as your area is at least 150m across at its narrowest point it is big enough for at least one turbine, so is viable.

  1. To create:

    1. Click Vector → Research Tools → Create Grid...
    2. Set Grid type as Hexagon (Polygon)
    3. Under Grid extent, click the drop-down arrow → Calculate from Layer → select your wind farm location polygon
    4. Set Horizontal spacing and Vertical spacing to 50 metres
    5. Set Grid CRS as EPSG:27700
    6. Click OK → Close
    7. Click Vector → Geometry Tools → Centroids...
    8. Set Input layer to the new Grid layer
    9. Click Run → Close
    10. Create buffer around those points
    11. Use Select by Location... BUT this time, only are within for your wind farm site(see)
    12. Export, check ‘save selected features’
    13. Use attribute table to count number of turbines
    14. Calculate their potential energy output in kWh

6.5 Creating a viewshed

  1. Install the Visibility Analysis plugin.

  2. Create a centroid point for your wind farm polygon (Vector → Geometry Tools → Centroids). This point represents the wind farm location for viewshed analysis.

  3. In the Processing Toolbox, run Visibility Analysis → Create Viewpoints. Set Observer locations = wind farm centroid; DEM = your tile DEM; Radius of analysis = 10 km; Observer height = 50 m; Target height = 2 m. Save the output viewpoint layer.

  4. Run Visibility Analysis → Analysis → Viewshed using the viewpoint layer and your tile DEM. Explore and understand the result.

6.6 Calculating impact

  1. Vectorise your viewshed (see Exercise 05) to create polygons representing areas within 10 km from which the wind farm is visible. Use select‑by‑value and save selected features.

  2. Using methods from Exercise 03, calculate the total number of people registered at postcodes within line‑of‑sight. If errors about “invalid geometry” occur, buffer the visibility polygon by 1 m and retry.

  3. Design Map 4 to present the wind farm location/extent and its visual impact. Focus on population and visibility; you do not need to repeat earlier context maps.

  4. Comment in your CW4 caption on how well your analysis captures potential impact if your wind farm lies near the tile edge.

TipLearning outcomes

By the end of this exercise you should:

  1. Create and edit a vector layer in QGIS.
  2. Create a new polygon layer to represent a proposed wind farm location.
  3. Calculate the area of a vector polygon and estimate turbine capacity.
  4. Create a viewshed using an observer/target and a DEM.
  5. Quantify population within sight of the proposed wind farm and its proportion of the tile population.
