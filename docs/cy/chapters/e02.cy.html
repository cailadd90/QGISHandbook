2  Composing maps in QGIS

Date of practical: 9th October 2025

Communication of geographical data and concepts through maps is a fundamental skill for spatial scientists. Creating maps requires both the ability to make them complete, correct and functional, and the flair to make them interesting and attractive. This exercise introduces the QGIS Print Layout window, and the final product represents your “Map 1”. assignment.

NoteLearning aims

To create functionally complete maps in QGIS for print or digital output. You will learn how to create a 1:1,000,000 scale map of Wales illustrating mean wind speed and county boundaries.

2.1 Creating a print layout

  1. Launch QGIS and create a new project

  2. Import the British_Isles_land_polygons.gpkg, Wales_border.gpkg, and Wales_Principal_Areas.gpkg layers (the latter two are in the UK_Boundaries folder)

  3. Label the Principal Areas of Wales in Welsh or English

  4. Click Project > New Print Layout... (and find the shortcuts to this window)

  5. Give the print layout an appropriate title

TipMultiple layouts

You can create more than one print layout. Use Project > Layout Manager... to easily access and organise layouts associated with your particular QGIS project.

  1. Arrange the Map Canvas and Print Layout windows so you can see both at once. Subsequent instructions refer to the Print Layout window unless otherwise stated

  2. Change the page orientation to A4 portrait:

    1. Right‑click on the blank print layout
    2. Click Page Properties...
    1. Change Size to A4
    2. Change Orientation to Portrait

2.2 Adding and adjusting a map item

  1. Click Add Item > Add Map (look for the shortcut)

  2. Draw a map onto the print layout. Map 1 should now appear under the Item tab

  1. Adjust the map using the squares around the edges

  2. Select Map 1

  3. Set Scale to 1000000 (i.e. 1:1,000,000)

  4. Use the Move item content () and Select/Move item () tools, and adjust the Scale value, to compose the map so that all of Wales is visible

  5. Experiment with making fine adjustments to the scale by holding down the Ctrl key and scrolling the mouse wheel

  6. Once you’re satisfied with the scaling, framing, and position, freeze the view in place by checking the box under the lock icon () for Map 1 in the Items panel

  7. In the Map Canvas window, adjust layer styles:

    1. Choose colours, border widths, and fonts that emphasise Wales and the difference between the outline of Wales (physical coast) and Principal Areas boundaries (non‑physical political construct)

  8. To force the Print Layout to reflect changes, select either:

    1. The Refresh icon () in the Print Layout window
    2. The Update Map Preview icon () under Item Properties in the Map Canvas window

  9. Ensure Map 1 is still selected

  10. Click on the Item Properties tab and add a Frame

  11. Modify the frame’s background colour appropriate for representing the ocean

TipModifying layers

You can modify the Layout and Item Properties of any item selected in the Item window. Note how the options under Layout and Item Properties tab update depending on what item you’ve selected. Remember that: (i) Order matters - the order in which map items are listed is how they are also stacked on top of one another in the print layout, and (ii) some layer properties (e.g. layer order, style, labeling) are controlled in the Map Canvas.

2.3 Adding a scale bar, north arrow, and grid

  1. Add a scale bar:

    1. Click Add Item > Add Scale Bar
    2. Click on the map to place it (you can move it later)
    3. Select the scale bar under Items
    4. Click the Item Properties tab
    5. Adjust the scale bar’s properties, notably Style, Scalebar units, Segments, Frame, and Background

  2. Add a north arrow:

    1. Click Add Item > Add North Arrow
    2. Click on the map to place it (you can move it later)
    3. Select the north arrow under Items
    4. Click the Item Properties tab
    5. Under SVG Images, search arrow and choose a suitable north arrow
    6. Adjust the north arrow’s properties, notably Fill color and Stroke color

  3. Add a grid (aka graticule):

    1. Select Map 1 under Items
    2. Click the Item Properties tab
    3. Expand Grids
    4. Click Add a new grid ()
    5. Click Grid 1 > Modify Grid...
    6. Set CRS to EPSG:4326 - WGS 84
    7. Set X and Y intervals to 1 degrees
    8. Check Draw Coordinates
    9. Adjust the grid’s properties, notably Grid type, Frame, and Draw Coordinates. Can you adjust the labels for readability, soften the gridlines, and reduce unnecessary trailing zeros?
TipReadjustments needed

You may find that some of the map items - notably the coordinates - are now beyond the edge of the page. These will be lost when the map is exported. In these cases, you will need to adjust the map size periodically as you experiment with how to best arrange map items and the caption (see Section 2.2). Check how using guides can aid you in aligning map items perfectly on the page.

2.4 Adding labels, and a legend

  1. Add a map title label:

    1. Click Add Item > Add Label
    2. Click on the map to place it (you can move it later)
    3. Select the label under Items
    4. Click the Item Properties tab
    5. Adjust the label’s properties, notably Main Properties, Font, Rotation, Frame, and Background

  2. Add a short caption label. See FAQ for how to have both bold and normal text in the caption at once

  3. Add a legend:

    1. Click Add Item > Add Legend
    2. Click on the map to place it (you can move it later)
    3. Select the legend under Items
    4. Click the Item Properties tab
    5. Uncheck Auto update to enable modifications to the legend
    6. Experiment with the legend toolbar icons () to improve the legend
    7. Adjust the legend’s properties, notably Arrangement, Fonts and Text Formatting, Columns, Symbol, Spacing, Frame, and Background

2.5 Adding raster data

  1. Add your first raster layer in QGIS. From the menu bar, click Layer > Add Layer > Add Raster Layer...

  2. Click the Browse icon () and navigate to the folder where the data is stored, i.e. GEG276

  3. Open the Wales_mean_windspeed folder and click on any of the .tif raster layers

  4. Click Open > Add > Close

  5. Open the layer’s Properties...

  6. Under Render type, select Singleband pseudocolor

  7. Under Color ramp, select an appropriate colour ramp for the data (or pick one you just really like!)

  8. Click OK

  9. Play around with Wales Principal Areas and the windspeed data - by adjusting the order of layers in the Layers panel, and by modifying the Properties... of each layer - so that both are visible at the same time. Hint: modifying Fill or Transparency properties may do nicely…

ImportantReadjustments needed

Avoid semi‑transparent symbology that breaks the link between map colours and legend colours.

  1. In the Print Layout window, select Map 1 and click Update Map Preview under the Item Properties tab

  2. If the colour scale for the raster layer does not appear in the legend, add it

  3. Experiment with improving the aesthetics of the updated legend

  4. Select Map 1 from the Items panel

  5. Under Item Properties, check the Lock layers and Lock styles for layers to prevent further changes to the map. Uncheck if you need to make edits

2.6 Adding an inset map

  1. Add a second map (see Section 2.2) to provide an inset showing the British Isles (e.g. at a scale of 1:20,000,000).

  2. Modify:

    1. Which layers should be displayed (by turning visibility on and off, or changing layer order)
    2. Their symbology (see Section 1.3);
TipModifying layers

Place emphasis on only a few, simply presented layers that are useful at this scale. Aim to be minimalist to avoid cluttering the map. Note that, because your map of Wales is locked, it’s not affected by changes in layer visibility or symbology being made for the inset. Herein lies the power of locking layers.

  1. Select Map 1 from the Items panel

  2. Under Item Properties, expand the Overviews tab

  3. Click Add a new overview ()

  4. Click Overview 1

  5. Set the Map frame to your Wales map

  6. Adjust the Frame style to draw a hollow rectangle with a thick line, to easily show the main map’s extent

  7. Experiment further, especially with Fill color, Stroke color, and Join style

TipKeeping things tidy

Projects can get rapidly out of control when multiple layers are used to build a map. It’s important to remove redundant layers and label items appropriately. E.g. try renaming Map 1 to Main, and Map 2 to Inset. This will help when you need to revisit and adjust your maps.

2.7 Exporting your map

  1. Ensure each map item has Lock layers checked. This helps ensure the chosen map scale (1:1,000,000) reflects real‑world distances

  2. Click Layout > Export as PDF... > Save, and save in a suitable location

  3. Set PDF Export Options as follows for best results:

    • ☑ Always export a vectors
    • Text export: Always Export Text as Paths
    • Image compression: Lossless
    • ☑ Disable tiled raster layer exports
    • ☑ Simplify geometries to reduce output file size

  4. Click Save. Congratulations - you’ve created your first QGIS map assignment. Now make any revisions to be able to submit the best Map 1 that you can!

NoteLearning outcomes

By the end of this exercise you should:

  1. Be familiar with the QGIS Map Layout and its relationship to the QGIS Project window.
  2. Know how to add and arrange essential map features and adjust their properties to make a map attractive.
  3. Know how to configure multiple map items, legends, grids, scales and labels in a map layout.
  4. Be able to export a map layout for inclusion in a document or presentation.
